# Página Informativa: Luan Santana

## Descrição do Projeto
Artigo digital focado na carreira, sucessos e trajetória do cantor e compositor Luan Santana, destacando seu papel na modernização do sertanejo no Brasil.

## Tema Escolhido
**Música e Cultura Popular Brasileira (Luan Santana)**

## Tecnologias Utilizadas
- **HTML5**: Estrutura semântica (`<header>`, `<nav>`, `<main>`, `<article>`, `<section>`, `<aside>`, `<footer>`).
- **CSS3**: Layout responsivo com Flexbox, estilização personalizada e efeitos `:hover`.
- **GitHub Pages**: Hospedagem e publicação do projeto.
